# Product demonstration guide

Use one fictional case: BDT 5,500 reported, BDT 5,000 on the first receipt and BDT 500 on the second. The outcome is reviewed preparation, not a recovered payment or official submission.

## Live walkthrough

Follow the [judge walkthrough](judge_quickstart.md). Show the discrepancy, original record, human review and changed result. Preview a fact change, review a draft and download preparation. Demonstrate Bangla and the separate synthetic administrative session as time permits.

If a reader/provider is unavailable, show the actual state and preserve the original for review. Do not substitute an invented inference.
