## Important findings after the initial audit

The initial audit did not identify the fabricated canonical-law subsection. This follow-up found it by comparing the actual primary text, removed it and replaced tests that had asserted the invented text. It also found that migrations lacked three runtime tables and a consent column: development auto-creation had concealed the gap. These are material findings, not merely documentation corrections.

The first scan implementation exposed a real PDF page-lifetime error; the implementation now shares the existing preview renderer and lock. Positive role-replacement tests subsequently exposed a uniqueness failure caused by INSERT preceding pending DELETE. An explicit transactional flush fixed it; promotion/demotion, privilege guards and role persistence after restart now pass. The failed role baseline is retained.

The initial local production persistence harness used the wrong preview URL and reported a 404 as a byte-persistence failure. The corrected owned-case URL passed; the failed harness result is retained and is not represented as a product storage defect. One intermediate regression run exposed genuine integration changes and stale fixture assumptions; its failed evidence is retained.
